# LLM-as-a-Judge Praktikum

This repository contains our code, notebooks, paper summaries, and results for the LLM-as-a-Judge Praktikum project.

## Project Goal

The goal of this project is to analyze how well different LLMs can act as judges.

We compare ratings generated by LLM judge models with human ratings and evaluate how strongly they correlate with each other. The analysis includes data loading, merging, correlation calculation, plotting, and interpretation of the results.

## Data

The required data should be cloned or downloaded from the original source when running the notebooks.

## Setup

Install the required packages with:

```bash
pip install -r requirements.txt
```

## How to Run

1. Clone this repository.
2. Open the notebooks in Google Colab.
3. Run the setup cells to install packages and clone/download the required data.
4. Run the analysis cells.
5. Save generated plots in `results/plots/` and result tables in `results/data/` if needed.

## Workflow

- Each person works in their own analysis notebook.
- Shared helper functions should be placed in `src/utils.py`.
- The combined analysis and comparison are collected in `notebooks/combined_analysis.ipynb`.
- Result data (CSV files) are stored in `results/data/`.
- Generated plots can be saved in `results/plots/`.

## Main Tasks

The main tasks of the project are:

1. Load the human rating dataset.
2. Load rating results from different LLM judge models.
3. Merge human ratings and model ratings.
4. Compute correlations between human ratings and model ratings.
5. Create plots and compare model behavior.
6. Summarize the findings for the poster presentation and final individual essays.

## Model Analysis

Each group member analyzes a subset of the models.

Possible aspects to analyze:

- Mean score
- Correlation with human ratings
- Strengths and weaknesses of each judge model
- Unusual patterns or outliers

## Results
